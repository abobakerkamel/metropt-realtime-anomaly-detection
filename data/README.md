# Data

The raw MetroPT-3 CSV is intentionally excluded from Git because it is about 208 MB.

Place the file here:

```text
data/raw/MetroPT3(AirCompressor).csv
```

Official source: https://archive.ics.uci.edu/dataset/791/metropt%203%20dataset

MetroPT-3 contains 1,516,948 time-series instances and 15 sensor features collected from a train air compressor.
